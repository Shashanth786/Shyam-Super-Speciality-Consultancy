# Shyam Super Speciality Consultancy Website

## Project Overview
A professional healthcare consultancy website showcasing services related to hospital empanelment, insurance claim management, government healthcare schemes, and healthcare staffing support.

## Key Features
- Company overview, vision, and mission
- Core healthcare consultancy services
- Institutional and hospital empanelment support
- Medical and non-medical staffing services
- Payment structure and consultancy expertise
- Contact information and navigation

## Technologies Used
- HTML
- CSS
- JavaScript
- Firebase Hosting
